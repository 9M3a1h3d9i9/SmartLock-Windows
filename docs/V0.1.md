# SmartLock-Windows — V0.1

## Purpose

This milestone converts SmartLock from a demo-oriented concept into the foundation of a maintainable Windows product.

## What V0.1 delivers

- Native WPF application shell on .NET 10.
- Domain/core layer isolated from WPF.
- Security event model and service contract.
- In-memory security event implementation for deterministic development and testing.
- Unit tests for validation, normalization, and event creation.
- Windows GitHub Actions CI for restore, build, and test.
- Architecture, contribution, and security documentation.
- Centralized compiler/analyzer settings and repository formatting rules.

## Explicit non-goals

V0.1 does not replace the Windows lock screen, intercept Winlogon, collect Windows credentials, or perform covert camera/biometric capture. Those boundaries are intentional product-security requirements.

## Quality gate

A V0.1 change is considered complete only when:

1. The solution restores successfully.
2. The solution builds in Release configuration.
3. Automated core tests pass.
4. Security-sensitive behavior has an explicit boundary.
5. Documentation reflects the implemented architecture.
6. The change is delivered in a focused Git commit.
