# V0.2 — Professional UI

## Goal

Move the development lock-screen experience from a minimal WPF view toward a maintainable, product-oriented UI foundation.

## Delivered

- Dedicated `SmartLock.UI` project.
- Shared WPF theme resources and design tokens.
- Professional dark surface, typography, spacing, borders, and status treatment.
- Explicit `DEVELOPMENT MODE` indicator.
- View-model layer with `LockScreenViewModel`.
- Authentication interaction moved out of the window code-behind into the view model.
- Dedicated UI unit tests for state changes and security-event behavior.
- Solution updated to include UI and UI test projects.

## Security boundary

V0.2 remains a development shell. It does not replace the Windows lock screen, intercept Winlogon, collect Windows credentials, or perform covert biometric/camera capture.

## Quality gate

Before marking V0.2 complete, CI must successfully restore, build, and test the complete solution on Windows.
